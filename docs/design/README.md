# 设计说明

## 视觉方向

“冷静的浅色证据审阅工作台”：纸白背景、墨蓝文字、电蓝关系线、绿色已验证状态和橙色风险提醒。视觉参考只用于理解层级和密度，页面由 Vue + DOM/CSS 实现，没有把参考图作为背景。

## 记忆点

页面中心是“证据匹配画布”，每一行都把 JD 能力要求、关系强度、来源项目与证据类型连成可审阅链路。它不是 KPI + 图表式后台，也不是营销落地页。

## 响应式策略

- 1920px：完整侧栏与宽证据画布。
- 1440px：压缩间距和辅助文案，不降低信息层级。
- 1366×768：保留核心三栏，内容区域纵向滚动，不产生页面横向溢出。
- 窄屏：侧栏收为图标轨道，核心区域改为纵向流。

## 交互与状态

- 搜索可过滤要求与证据行。
- Provider 模式可切换展示，但只有 `local-rule` 标为当前可用演示模式。
- Human Review 清晰区分 `Draft`、待确认与 `Confirmed`。
- 支持键盘焦点与 `prefers-reduced-motion`。
