# 项目边界

## 允许范围

- 使用虚构岗位与匿名化项目样例展示证据链工作流。
- 使用确定性的 `local-rule` 生成演示拆解和匹配结果。
- 由用户主动粘贴、确认和修改非敏感内容。
- 生成必须经过人工复核的面试准备草稿。

## 明确不做

- 不接 Boss、牛客、实习僧等招聘平台 API，不爬取网页。
- 不采集或保存真实手机号、邮箱、身份证、聊天记录等隐私。
- 不辅助实时面试作弊或隐蔽提示。
- 不计算 Offer/录取概率，不保证通过。
- 不宣称生产级招聘系统、真实客户、真实流量或商业数据。
- 不将规则 fallback 包装成真实 LLM，也不声称 Provider 已稳定接入。

## 人工复核原则

AI 或规则生成的内容默认是 `Draft`。用户必须确认事实、措辞和证据来源后，才能将内容标记为 `Confirmed` 并复制使用。
